MQL Queries:
1) To check the list of databases:
-> show dbs

2) To create or switch to db:
Syntax: use database_name;

Ex: use demo_db;

3) Creating collection(table) in mongoDB:
Syntax: db.createCollection("collection_name");

Example: db.createCollection("college");

4) To check the list of collections:
-> show collections

CRUD Operations:
C - CREATE/INSERT - insertOne, insertMany
R - READ/FETCH - find, findOne
U - UPDATE
D - DELETE

5) To insert one document in the collection: insertOne()
Syntax: db.collection.insertOne({"key1" : "value1", "key2" : "value2"})

Example: db.college.insertOne(
    {
        "name": "NIE", 
        "location": "North Campus", 
        "city": "Mysuru", 
        "affliation": "VTU (Autonomous)"
    }
)

db.college.insertOne(
    {
        "name": "NIE", 
        "location": "South Campus", 
        "city": "Mysuru", 
        "affiliation": "VTU (Autonomous)",
        "branches" : "ECE, CIVIL, MECH"
    }
)

6) To insert bulk documents in the collection: insertMany()
Syntax: db.collection.insertMany([{"key1" : "value1", "key2" : "value2"},{"key1" : "value1", "key2" : "value2"}])

Example: 
db.college.insertMany([
    {
        "name": "Maharaja College", 
        "city": "Mysuru", 
        "affiliation": "Mysuru University",
        "specilization" : "B.E, B.Com, B.Sc"
    },
    {
        "name": "Bn Bahadur Institute of Management Studies",  
        "city": "Mysuru", 
        "established": 2002, 
        "affiliation": "Mysuru University",
        "branches" : "BBA, MBA"
    }
])

$gt - greater than
$lt - lesser than
$eq - equal to
$ne - not equal to
$gte - greater than or equal to
$lte - lesser than or equal to

While using comparison operators:
Syntax:
db.collection.find(
    {
        field : { $operator : value }
    }
)

db.students.find(
    {
        age : { $gt : 24 }
    }
)

db.students.find(
    {
        age : { $lt : 24 }
    }
)

db.students.find(
    {
        age : { $lte : 24 }
    }
)

db.students.find(
    {
        age : { $eq : 24 }
    }
)

db.students.find(
    {
        age : { $ne : 24 }
    }
)

7) To update the existing documents: updateOne()
Syntax: db.collection.updateOne(
    { field : value },
    { $set : { field : new_value, field2 : value2 } }
)

db.college.updateOne(
    {
        location: 'North Campus'
    },
    {
        $set : {
            college_code : "NIE-N"
        }
    }
)

db.college.updateOne(
    {
        location: 'South Campus'
    },
    {
        $set : {
            college_code : "NIE-S",
            cet_code : "NIES123"
        }
    }
)

8) To update the multiple documents: updateMany()
Syntax: db.collection.updateMany(
    { field : value },
    { $set : { field : new_value, field2 : value2 } }
)

db.college.updateMany(
    {
        city : "Mysuru"
    }, 
    {
        $set : {
            district : "Mysuru",
            "state" : "Karnataka"
        }
    }
)

db.college.updateMany(
    {
        affiliation : "Mysuru University"
    }, 
    {
        $set : {
            affiliation : "Kuvempu University"
        }
    }
)

$and & $or logical operators:
Syntax:
db.collection.find({
    $and / $or : [
        { field1 : value1 },
        { field2 : value2 }
    ]
})

Ex:
db.students.find({
    $and : [
        { branch : "CSE" },
        { section : "A" }
    ]
})

In another way, to use "and" condition
db.students.find(
    { 
        branch : "CSE", section : "A" 
    }
)

db.students.find({
    $and : [
        { branch : "CSE" },
        { age : 26 }
    ]
})

db.students.find({
    $or : [
        { branch : "CSE" },
        { age : 26 }
    ]
})

9) To delete the existing document: deleteOne()
Syntax: db.collection.deleteOne(
    { field1 : value1 }
)

Ex:
db.college.deleteOne(
    { established : 2002 }
)

db.students.deleteOne(
    { name: 'Hemanth' }
)

10) To delete multiple documents: deleteMany()
Syntax: db.collection.deleteMany(
    { field1 : value1 }
)

Ex:
db.students.deleteMany(
    { branch : "CSE", sem : 8 }
)

db.students.deleteMany(
    { age : { $gt: 21 } }
)
